# 🌍 KaanCraft: 3D WebGL Voxel Survival Engine

> **Live Demo:** [Play KaanCraft Here!](https://kaancraft.netlify.app) 🎮

Hi there! 👋 I'm Kaan, a young self-taught software developer from Turkey. This is my open-source passion project: **KaanCraft**. It is a fully functional 3D voxel survival game running entirely in the browser using a single HTML file and Three.js!

I love exploring Linux, networking, and game mechanics, and I built this project to challenge myself and learn more about 3D programming, procedural generation, and open-source culture.

---

## ✨ Features
- **Infinite World Generation:** Procedural terrain generation using Perlin Noise (mountains, oceans, forests).
- **Physics Engine:** Falling sand and flowing water mechanics.
- **Dynamic Lighting & Shadows:** Real-time sun movement, ambient occlusion, and glowing ores.
- **Survival Mechanics:** Health and hunger bars, inventory system, and block breaking/placing.
- **Immersive Audio:** Procedural sound synthesis via Web Audio API (no external MP3s!) including footstep variations for dirt, stone, and water.
- **Music Player:** Toggleable ambient background music generated entirely by code.

## 🕹️ Controls
| Key/Mouse Action | What it does |
| :--- | :--- |
| **W, A, S, D** | Move around the world |
| **Space** | Jump / Swim in water |
| **Shift** | Sprint |
| **Left Click (Hold)** | Break blocks (Mine) |
| **Right Click** | Place block |
| **E** | Open / Close Inventory & Crafting Menu |
| **G** | Toggle Gamemode (Survival / Creative) |
| **M** | Toggle ambient background music |
| **1-9 / Scroll** | Select item from Hotbar |
| **ESC** | Pause / Free mouse cursor |

---

## 🚀 How to Run Locally
Since it's built in a single HTML file, you don't need any complex servers!
1. Clone this repository or download the `index.html` file.
2. Double click `index.html` to open it in your browser (Brave, Chrome, Firefox).
3. Enjoy!
